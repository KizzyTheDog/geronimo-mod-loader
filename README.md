# GERONIMO Mod Hub

Mod loader, manager and community browser for GERONIMO (Steam 2019620). Supports GML plugins
(compatible with [RemArrow's GERONIMO Mod Loader](https://github.com/RemArrow/geronimo-mod-loader)),
UE4SS mods and pak mods. Tauri 2 + React + TypeScript.

Status: early UI shell (sample data, no install logic yet).

```
npm install
npm run tauri dev
```
